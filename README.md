# Alem Events — объяснимый подбор подрядчиков

Локальный веб-сервис для команды и жюри HackAlem: задайте город, дату,
мероприятие, категорию и бюджет; при необходимости — часы и язык. Сервис
вернёт до трёх карточек с объяснениями и причины малого или пустого результата.

## Запуск

Python 3.9+, без сторонних зависимостей и API-ключей:

```bash
python3 server.py
```

Откройте **http://127.0.0.1:8000**. Завершение — Ctrl+C.
Другой порт: `python3 server.py --port 8080`.
Для демонстрации другим устройствам в локальной сети:
`python3 server.py --host 0.0.0.0 --port 8000`, затем откройте адрес компьютера
в этой сети. Это демо-сервер стандартной библиотеки, не публичный production-хостинг.
Развёрнутой внешней версии нет.

## Что реализовано

- Форма с опциями из реального каталога, необязательными часами и языком.
- Карточки с ценами «от», фактами и отметками происхождения данных.
- Причины отсева, сводка для пустой и неполной выдачи.
- Сравнение двух дат с одинаковыми условиями рядом.
- Кнопки проверенных демо: плотная категория, редкая категория, пустая выдача,
  отсутствие категории и сравнение дат.
- Адаптивная вёрстка, состояния загрузки и ошибок.
- HTTP API `GET /api/meta`, `POST /api/recommend`.
- Серверная валидация, ограничение размера запроса, выдача только разрешённых
  статических файлов. Данные карточек вставляются как текст, не HTML.

## Пайплайн

`CSV + HTML → ingest.py → data/profiles.json → matching.py → explanations.py → server.py → web/`

1. Источники сверяются по `id`, без слепого объединения.
2. Полные записи берутся из CSV, числа, списки и даты нормализуются.
3. Фильтры: город → категория → дата → бюджет → формат → язык → часы.
4. Прошедшие кандидаты ранжируются по меньшей цене, затем строковому `id`.
5. Объяснения формируются из фактов и фрагментов описаний, без внешней AI-модели.

Подробнее об объяснениях: [EXPLANATIONS.md](EXPLANATIONS.md).
Сценарий выступления: [DEMO.md](DEMO.md).

## Данные и происхождение профилей

Предоставлены CSV и HTML: `data/source/`. По 66 профилей, одинаковые `id`,
расхождений в сопоставимых полях нет — см. `data/comparison.json`.
HTML содержит сокращённые описания и количества занятых дней, поэтому
конкретные даты берутся из CSV. Календарь: **23.09–31.12.2026**.
За пределами периода доступность считается неизвестной, профиль отсеивается.

Синтетические записи исходного датасета получают отметку «Синтетический профиль».
Добавленные командой записи нужно помещать отдельно в `data/team_profiles.json`
в нормализованной схеме `data/profiles.json`, с уникальными `id`.
Сервер назначает им `team_added: true` и отметку «Добавлен командой».
Если запись искусственная, также укажите `synthetic: true` — появятся обе отметки.
Сейчас файл пуст, добавленных командой профилей нет. После изменения данных
перезапустите сервер. Дубликаты `id` блокируют загрузку.

Пересоздать нормализованный датасет:

```bash
python3 ingest.py data/source/profiles.csv data/source/preview.html
```

При конфликтах создаётся отчёт, но новый `profiles.json` не записывается.
Старый файл остаётся и не должен считаться результатом неуспешного импорта.

## API и проверки

```bash
curl http://127.0.0.1:8000/api/recommend \
  -H 'Content-Type: application/json' \
  --data-binary @examples/dataset_request.json

python3 -m unittest discover -s tests -v
python3 quality_demo.py
```

Обязательные поля JSON: `city`, `date`, `format`, `category`, `budget`.
Необязательные: `language`, `duration_hours` (можно `null`).
Ответ содержит `cards`, `message`, `status`, `exclusion_counts`, а также
исходные `candidates`, `rejected`, `eligible_count`, `quality`.
Некорректный запрос возвращает HTTP 400; слишком большой — 413.
Тесты покрывают алгоритм, объяснения, сверку файлов, HTTP-запросы всех демо,
некорректный ввод и маркировку профилей команды.

## Ограничения

Цена «от» не гарантирует итоговую стоимость. Отсутствие даты в списке занятых
не подтверждает бронь. `max_hours: null` означает отсутствие ограничения по
присутствию. Флаги восстановленных города и цены показаны в карточках.
Описания принадлежат источнику и не являются проверенными рекомендациями.
Нет бронирования, авторизации, почасовых тарифов, конвертации валют и обработки
синонимов. Бюджет в KZT. XLSX не читается, поскольку предоставлен CSV.
HTML-парсер предназначен для структуры данного превью.
Внешние API не используются. Визуальная проверка в браузере автоматически
не выполнялась; синтаксис JavaScript и HTTP-сценарии проверяются отдельно.
